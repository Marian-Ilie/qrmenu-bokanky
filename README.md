# 🍕 Bokanky Pizzeria - Digital Menu & Phygital Experience

A high-performance, mobile-first digital menu built for a local restaurant&pizzeria. This project represents a complete end-to-end overhaul of the restaurant's digital infrastructure, transitioning from an obsolete, slow third-party system to a custom-built, blazing-fast web application.

Beyond the code, this project encompasses a complete Phygital (Physical + Digital) User Experience redesign, optimizing the physical QR scanning process in the restaurant to ensure a frictionless transition from the table to the digital menu.

## 🎯 The Problem & The Solution

### The Challenge
The client was tied to a restrictive third-party platform that suffered from slow load times, poor mobile optimization and lack of maintenance.

### The Solution
1. **Digital:** Engineered a custom, lightweight Next.js application deployed on Vercel's Edge Network to guarantee instant load times (under 1 second) upon scanning.
2. **Physical:** Designed and applied custom matte PVC QR stickers over the special metal stands, creating maximum optical contrast. This reduced scan-to-load time from ~5 seconds to an instant, seamless action.

## ✨ Key Features & UX Highlights

### 📱 Mobile-First UI/UX Design
- **Thumb-Zone Navigation:** Categories and critical actions are placed within easy reach of the user's thumb for comfortable one-handed use.
- **Typographic Hierarchy:** High-contrast typography ensures readability in various lighting conditions (e.g., dim restaurant lighting or bright outdoor terraces).
- **Reduced Cognitive Load:** Clean layouts and intuitive categorization allow hungry customers to find their desired pizza in seconds without being overwhelmed by visual clutter.

### 🚀 Technical Performance
- **Instant Load Times:** Built with Next.js and optimized for static delivery where possible, ensuring zero wait time.
- **Secure & Independent:** Fully migrated to a dedicated infrastructure on Vercel with automatic SSL renewal, breaking free from unreliable legacy hosting.
- **SEO & Metadata:** Properly configured metadata for link sharing and local search visibility.

### 🌉 The "Phygital" Bridge (Physical-to-Digital UX)
A core component of this project was optimizing the physical touchpoint. Recognizing that the digital experience begins before the screen turns on:
- Placed QR codes on both sides of the table stands.
- This physical UX optimization guarantees that any smartphone camera, regardless of generation, can lock onto the code instantly without glare interference.

## 💻 Getting Started (Local Development)
To run this project locally, follow these steps:

1. Clone the repository:
```bash
git clone https://github.com/yourusername/bokanky-menu.git
```

2. Install dependencies:
```bash
cd bokanky-menu
npm install
# or yarn install
```

3. Run the development server:
```bash
npm run dev
# or yarn dev
```

Open `http://localhost:3000` in your browser to see the result.
